# Security Policy / 安全说明

## 中文

如果你发现安全问题，请不要在公开 Issue 中直接披露可利用细节。可以先在本地复现并整理以下信息：

- 受影响模块和接口。
- 触发条件和影响范围。
- 是否涉及明文密码、token 泄露、越权、SQL 注入、SSRF、RCE 或敏感数据暴露。
- 建议修复方向。

当前项目是学习与复盘性质的公开仓库，不承诺生产级安全响应 SLA。涉及密钥、证书私钥、真实账号、真实用户数据的内容不应提交到仓库。

## English

If you discover a security issue, please do not disclose exploitable details in a public issue. Prepare the following information first:

- Affected module and API.
- Trigger conditions and impact scope.
- Whether it involves plaintext passwords, token leakage, broken authorization, SQL injection, SSRF, RCE, or sensitive data exposure.
- Suggested mitigation or fix direction.

This is a public learning and review repository, so it does not provide a production-grade security response SLA. Secrets, private keys, real accounts, and real user data should never be committed.
